# Support

Report reproducible bugs and scoped feature requests through [GitHub Issues](https://github.com/cixiangtao/codex-project-chats/issues). English and Simplified Chinese reports are welcome.

Include the extension version, VS Code version, official Codex extension version, OS/architecture, local or remote workspace mode, and minimal reproduction steps. Use anonymized sample paths. State whether opening the same conversation directly in official Codex works.

Do not attach raw Codex databases, transcripts, authentication files, account credentials, complete logs, or real conversation IDs. Review screenshots and logs before sharing them. For vulnerabilities, use the private reporting path in [SECURITY.md](https://github.com/cixiangtao/codex-project-chats/blob/main/SECURITY.md).

For problems reproducible without this extension, report them to the relevant upstream project. This project cannot guarantee the stability of upstream Codex interfaces. Support is best effort; no response-time commitment is made.
